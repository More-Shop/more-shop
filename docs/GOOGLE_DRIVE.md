# เก็บรูปภาพไว้ใน Google Drive

รูปเมนู โลโก้ร้าน และรูปใบเสร็จรายจ่าย ของแต่ละร้าน **เก็บในโฟลเดอร์ Google Drive ของร้านนั้น**
ไม่กินพื้นที่ฐานข้อมูล Supabase (หลักการเดียวกับระบบเดิมที่ใช้ Apps Script บันทึกสลิปลง Drive)

```
โฟลเดอร์ของร้าน (ที่คุณสร้าง)
├── เมนู/              ← รูปเมนูจากหน้า "เมนูและราคา"
├── โลโก้/             ← โลโก้จากหน้า "ตั้งค่าร้าน"
└── ใบเสร็จรายจ่าย/    ← รูป/PDF ที่แนบในหน้า "รายรับ-รายจ่าย"
```

ระบบสร้างโฟลเดอร์ย่อยให้เอง และย่อรูปให้ประมาณ 100–200 KB ก่อนอัปโหลด

## ขั้นที่ 1 · ติดตั้ง Apps Script (ทำครั้งเดียว ใช้ได้ทุกร้าน)

ทำด้วยบัญชี Google ที่จะเป็นเจ้าของรูปทั้งหมด

1. เปิด <https://script.google.com> → **New project** → ตั้งชื่อ `More Shop Drive`
2. ลบโค้ดเดิมใน `Code.gs` แล้ววางเนื้อหาไฟล์ [`apps-script/DriveUpload.gs`](../apps-script/DriveUpload.gs) ทั้งไฟล์ → กด 💾 Save
3. เลือกฟังก์ชัน **authorize** ที่แถบด้านบน → กด **Run** → อนุญาตสิทธิ์
   (ถ้าเจอ “Google hasn’t verified this app” กด *Advanced → Go to More Shop Drive*)
4. กด **Deploy → New deployment** → ⚙️ เลือก **Web app**
   - *Execute as:* **Me**
   - *Who has access:* **Anyone**
   - กด **Deploy** แล้วคัดลอก **Web app URL** (ขึ้นต้น `https://script.google.com/macros/s/…/exec`)

> สคริปต์ปลอดภัย: ทุกครั้งที่อัปโหลด สคริปต์จะถามฐานข้อมูลด้วยการล็อกอินของผู้ใช้คนนั้นว่าเป็นพนักงานของร้านจริงไหม
> และใช้โฟลเดอร์ที่บันทึกไว้ในฐานข้อมูลเท่านั้น คนนอกจึงอัปโหลดเข้าโฟลเดอร์ใด ๆ ไม่ได้

## ขั้นที่ 2 · ตั้งค่าแต่ละร้าน

1. สร้างโฟลเดอร์ใน Google Drive สำหรับร้าน เช่น `More Shop - รูปภาพ`
   - ถ้าโฟลเดอร์อยู่ในบัญชี Google อื่น (เช่น อีกร้านใช้ Drive ของตัวเอง) ให้ **แชร์โฟลเดอร์นั้นให้บัญชีที่ติดตั้งสคริปต์เป็น “ผู้แก้ไข”**
2. เปิดโฟลเดอร์ → คัดลอกลิงก์จากแถบที่อยู่ เช่น `https://drive.google.com/drive/folders/1AbC…`
3. ในระบบ More Shop → **ตั้งค่าร้าน → ที่เก็บรูปภาพ (Google Drive)**
   - **ลิงก์โฟลเดอร์ Google Drive ของร้าน:** วางลิงก์จากข้อ 2
   - **ลิงก์ Apps Script:** วาง Web app URL จากขั้นที่ 1
4. กด **บันทึกการตั้งค่า** → ลองอัปโหลดโลโก้หรือรูปเมนู แล้วเปิดโฟลเดอร์ใน Drive ดูว่ามีไฟล์เข้า

## แก้ปัญหา: “ไม่ได้รับอนุญาตให้เข้าถึง DriveApp” / “You do not have permission to call DriveApp”

สคริปต์ยังไม่ได้รับสิทธิ์ Google Drive (หน้าขออนุญาตของ Google ให้ติ๊กทีละข้อ ถ้าไม่ได้ติ๊ก Google Drive จะเกิดข้อความนี้)

1. เปิดโปรเจกต์ Apps Script → เลือกฟังก์ชัน **authorize** → **Run**
2. หน้าขออนุญาต: กด **Select all / เลือกทั้งหมด** หรือติ๊ก **ทุกช่อง** (โดยเฉพาะ *ดู แก้ไข สร้าง และลบไฟล์ Google ไดรฟ์*) → **Continue**
   - ถ้ากด Run แล้วไม่มีหน้าขออนุญาตขึ้น: ไปที่ <https://myaccount.google.com/connections> → เลือกชื่อโปรเจกต์ → **ลบการเข้าถึง** → กลับมากด Run ใหม่
3. ดู *Execution log* ต้องขึ้น `Google Drive: OK`
4. **Deploy → Manage deployments → ✏️ (แก้ไข) → Version: New version → Deploy** (ลิงก์เดิม ไม่ต้องเปลี่ยนในระบบ)
   - ตรวจว่า *Execute as* = **Me** (ถ้าเป็น “User accessing the web app” จะเกิดข้อความนี้เช่นกัน)

### รูปเข้า Drive แล้ว แต่หน้าเว็บขึ้น error
ถ้าโฟลเดอร์ของร้านแชร์แบบ “ทุกคนที่มีลิงก์ = ผู้แก้ไข” Google จะไม่ยอมให้สคริปต์ตั้งไฟล์เป็น “ดูได้อย่างเดียว”
ให้ตั้งโฟลเดอร์เป็น **จำกัด** (ปลอดภัยกว่าด้วย — สคริปต์จะเปิดให้ดูได้ทีละไฟล์เอง) และใช้สคริปต์เวอร์ชันล่าสุด

## หมายเหตุ

- ไฟล์ถูกแชร์แบบ “ทุกคนที่มีลิงก์ดูได้” เพื่อให้แสดงรูปเมนูบนหน้าลูกค้าได้ (เหมือนสลิปในระบบเดิม)
- ร้านที่ยังไม่ได้ตั้งโฟลเดอร์ จะเก็บรูปใน Supabase Storage ชั่วคราวแทน (แผนฟรีมี 1 GB)
- พื้นที่ที่ใช้นับในบัญชี Google ของผู้ที่ติดตั้งสคริปต์ (เจ้าของไฟล์)
- อัปเดตสคริปต์ภายหลัง: แก้โค้ด → **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** (URL เดิม)
