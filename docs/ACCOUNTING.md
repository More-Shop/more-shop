# บัญชีและรายงานภาษี

## ข้อมูลเข้าบัญชีอย่างไร

| แหล่ง | การบันทึก |
|---|---|
| เช็คบิล (POS / QR / LINE) | บันทึกเป็น **รายรับ** บัญชี 4100 อัตโนมัติ พร้อมเลขที่ใบเสร็จ ยอด VAT และวิธีชำระเงิน |
| ยกเลิกใบเสร็จ | รายการบัญชีถูกทำเครื่องหมาย “ยกเลิก” (เลขที่เอกสารไม่หาย ตามหลักเลขที่ต่อเนื่อง) |
| รายจ่าย / รายรับอื่น | บันทึกเองในหน้า *รายรับ-รายจ่าย* พร้อมผู้ขาย เลขผู้เสียภาษี สาขา เลขที่ใบกำกับ และรูปใบเสร็จ |

เลขที่ใบเสร็จรันต่อเนื่องรายเดือนต่อร้าน: `INV2611-00001` (ร้านจด VAT) หรือ `RC2611-00001`

## รายงาน (เมนู *รายงานบัญชี/ภาษี*)

ทุกรายงานเลือกช่วงรายเดือน / รายปี / กำหนดเอง และออกได้ 2 แบบ
**พิมพ์ / PDF (A4)** พร้อมช่องลงนาม และ **CSV** (เปิดใน Excel ภาษาไทยไม่เพี้ยน)

| รายงาน | ใช้สำหรับ |
|---|---|
| **รายงานเงินสดรับ-จ่าย** | บุคคลธรรมดาที่มีเงินได้จากธุรกิจ (มาตรา 40(8)) และเลือกหักค่าใช้จ่ายตามจริง — ใช้ประกอบ ภ.ง.ด.94 / ภ.ง.ด.90 หัวรายงานมีชื่อผู้ประกอบการ เลขผู้เสียภาษี ชื่อและที่อยู่สถานประกอบการ ยอดขายรวมเป็นรายวันพร้อมช่วงเลขที่ใบเสร็จ |
| **รายงานภาษีขาย** | ผู้ประกอบการจดทะเบียน VAT ประกอบ ภ.พ.30 รายเดือน — ใบกำกับภาษีอย่างย่อรวมเป็นรายวัน (เลขที่ตั้งแต่–ถึง), ใบกำกับภาษีเต็มรูปแสดงทีละฉบับพร้อมชื่อ เลขผู้เสียภาษี และสาขาผู้ซื้อ |
| **รายงานภาษีซื้อ** | ประกอบ ภ.พ.30 — รายจ่ายที่มีใบกำกับภาษี พร้อมชื่อ/เลขผู้เสียภาษี/สาขาผู้ขาย และเตือนเมื่อข้อมูลผู้ขายไม่ครบ |
| **งบกำไรขาดทุน** | Income Statement จำแนกตามหน้าที่ (รายได้ → ต้นทุนขาย → กำไรขั้นต้น → ค่าใช้จ่ายดำเนินงาน → กำไรจากการดำเนินงาน → ต้นทุนทางการเงิน → กำไรก่อนภาษี → ภาษีเงินได้ → กำไรสุทธิ) ร้านจด VAT แสดงมูลค่าไม่รวม VAT |
| **สมุดรายวันทั่วไป** | General Journal แบบบัญชีคู่ (Dr/Cr ยอดสมดุล) — เงินสด 1000, ธนาคาร 1010, ภาษีซื้อ 1150, ภาษีขาย 2150 — ส่งต่อสำนักงานบัญชีหรือนำเข้าโปรแกรมบัญชี |
| **สรุปยอดขายรายวัน** | ยอดขายแยกตามเงินสด / พร้อมเพย์ / โอน / บัตร |

## ผังบัญชี

ผังบัญชีเริ่มต้นใช้รหัสแบบสากล (4xxx รายได้, 5xxx ค่าใช้จ่าย) และจัดกลุ่มสำหรับงบกำไรขาดทุน
(รายได้, รายได้อื่น, ต้นทุนขาย, ค่าใช้จ่ายดำเนินงาน, ต้นทุนทางการเงิน, ภาษีเงินได้)
เพิ่มบัญชีของร้านเองได้ที่ *รายรับ-รายจ่าย → ผังบัญชี*

## ข้อควรทราบ

- รายงานจัดทำตาม **เกณฑ์เงินสด** จากรายการในระบบ — นิติบุคคลที่ต้องจัดทำงบการเงินตามเกณฑ์คงค้าง
  และให้ผู้สอบบัญชีรับรอง ควรส่ง *สมุดรายวันทั่วไป* (CSV) ให้สำนักงานบัญชีปรับปรุงรายการก่อนยื่น
- เก็บเอกสารประกอบ (ใบเสร็จ/ใบกำกับภาษี) ไว้อย่างน้อย 5 ปี — แนบรูปไว้ในระบบได้
- ระบบช่วยจัดทำรายงาน แต่ผู้ประกอบการควรตรวจสอบความถูกต้องกับผู้ทำบัญชี/ผู้สอบบัญชีก่อนยื่นจริง
