# ผู้ดูแลระบบ (Platform admin)

หน้าผู้ดูแลระบบเป็น **เว็บแยกจากหน้าร้าน** และมีการเข้าสู่ระบบของตัวเอง:

**https://more-shop.github.io/more-shop/admin.html**

- หน้าร้านไม่มีปุ่มหรือลิงก์ไปหน้านี้เลย
- บัญชีที่ไม่ใช่ผู้ดูแลระบบ เข้าสู่ระบบแล้วจะเห็นแค่ “ไม่มีสิทธิ์เข้าหน้านี้” และฐานข้อมูลปฏิเสธคำสั่งผู้ดูแลทุกคำสั่งจากบัญชีอื่น
- กด “เข้าจัดการร้าน” จะเปิดระบบร้านในแท็บใหม่ (ถ้ายังไม่ได้เข้าสู่ระบบร้านในเบราว์เซอร์นั้น ให้เข้าสู่ระบบด้วยบัญชีผู้ดูแลอีกครั้ง)

| แท็บ | ทำอะไรได้ |
|---|---|
| **ภาพรวม** | จำนวนสมาชิกรออนุมัติ / ใช้งาน / ระงับ, ยังไม่ยืนยันอีเมล, จำนวนร้าน, ยอดขายวันนี้ทุกร้าน, ปัญหาค้าง |
| **สมาชิก** | อนุมัติ / ไม่อนุมัติ / ระงับ / เปิดใช้งาน, เขียนหมายเหตุถึงผู้ใช้, **ยืนยันอีเมลให้** (กรณีอีเมลยืนยันไม่มา), ส่งลิงก์ตั้งรหัสผ่านใหม่, ตั้ง/ยกเลิกผู้ดูแลระบบ, ดูร้านที่สังกัดและเข้าไปจัดการ |
| **ร้านค้า** | ทุกร้านพร้อมสถิติ 7 วัน และ **ตรวจสุขภาพร้าน** (เมนู โต๊ะ พร้อมเพย์ ข้อมูลภาษี Google Drive LINE บิลค้าง ออเดอร์รอยืนยันนาน) — กดรายการที่ขึ้นสีส้มเพื่อไปแก้ทันที, **เข้าจัดการร้าน** (ทำได้ทุกอย่างแทนเจ้าของร้าน), เพิ่มสมาชิก/โอนร้าน |
| **ปัญหาที่พบ** | ข้อความ error ที่สมาชิกและลูกค้าเห็นบนหน้าจอ (บันทึกอัตโนมัติ) รวมข้อความซ้ำ บอกผู้ใช้ ร้าน หน้า และอุปกรณ์ — กด “เปิดร้าน” เพื่อเข้าไปแก้ แล้วกด “แก้แล้ว” |

## การอนุมัติสมาชิก

- ทุกคนที่สมัครใหม่จะอยู่สถานะ **รออนุมัติ** — เข้าสู่ระบบได้แต่ใช้งานไม่ได้ จนกว่าผู้ดูแลจะอนุมัติ
- ฟอร์มสมัครเก็บ ชื่อ เบอร์โทร และชื่อร้าน ไว้ให้ผู้ดูแลใช้ประกอบการอนุมัติ
- **พนักงานร้าน:** เมื่อเจ้าของร้านเพิ่มอีเมลในหน้า “พนักงาน” บัญชีนั้นจะได้รับการอนุมัติอัตโนมัติ
- **ระงับ:** บัญชีที่ถูกระงับเข้าร้านใดไม่ได้เลย (ข้อมูลร้านยังอยู่ครบ) เปิดใช้งานคืนได้ทุกเมื่อ

## ตั้งผู้ดูแลระบบคนแรก

ทำครั้งเดียวใน Supabase → SQL Editor:

```sql
insert into public.platform_admins (user_id)
select id from auth.users where email = '<อีเมลของคุณ>';
```

ผู้ดูแลคนต่อไปตั้งได้จากแท็บ **สมาชิก → ตั้งเป็นผู้ดูแลระบบ** (ระบบไม่ยอมให้ลบผู้ดูแลคนสุดท้าย)
