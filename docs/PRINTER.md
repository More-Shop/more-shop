# เครื่องพิมพ์ใบเสร็จ (Thermal 58 / 80 มม.)

ระบบพิมพ์ผ่านหน้าต่างพิมพ์ของเบราว์เซอร์ จึงใช้ได้กับเครื่องพิมพ์ทุกตัวที่อุปกรณ์มองเห็น
เอกสารที่พิมพ์ได้:

- **ใบสั่งครัว** — เลขโต๊ะตัวใหญ่ รายการ จำนวน หมายเหตุ (พิมพ์อัตโนมัติเมื่อกด “ส่งออเดอร์” / “ยืนยันส่งครัว”)
- **ใบแจ้งยอด (Check bill)** — พร้อม QR พร้อมเพย์ใส่ยอดเงินให้ลูกค้าสแกนจ่าย
- **ใบเสร็จรับเงิน / ใบกำกับภาษีอย่างย่อ / ใบกำกับภาษีเต็มรูป**
- **QR Code ประจำโต๊ะ** (สแกนแล้วสั่งอาหาร), QR จองโต๊ะ, QR เพิ่มเพื่อน LINE
- **รายงานบัญชี A4** (ใช้เครื่องพิมพ์ธรรมดา หรือ “บันทึกเป็น PDF”)

ตั้งขนาดกระดาษ 58 หรือ 80 มม. ได้ที่ *ตั้งค่าร้าน → การรับเงินและใบเสร็จ* และกด
**ทดสอบพิมพ์ใบเสร็จ** เพื่อตรวจ

## iPad / iPhone

iOS พิมพ์ได้เฉพาะเครื่องพิมพ์ที่รองรับ **AirPrint** — เลือกรุ่นที่รองรับ AirPrint โดยตรง เช่น

- Epson TM-m30II / TM-m30III (LAN / Wi-Fi)
- Star Micronics mC-Print3, TSP143IV (LAN / USB-C)

เชื่อมเครื่องพิมพ์กับ Wi-Fi เดียวกับ iPad → กดพิมพ์ในระบบ → เลือกเครื่องพิมพ์ → พิมพ์
(ครั้งต่อไป iOS จำเครื่องพิมพ์ล่าสุดไว้)

## Android แท็บเล็ต

- เครื่องพิมพ์ LAN/Wi-Fi: ติดตั้ง *Print Service* ของยี่ห้อนั้น (เช่น Epson iPrint, Star Print Service) หรือ *Mopria*
- เครื่องพิมพ์ Bluetooth ราคาประหยัด (Xprinter, GOOJPRT ฯลฯ): ติดตั้งแอป **RawBT** แล้วเปิด *RawBT Print Service*
  จากนั้นเลือก RawBT เป็นเครื่องพิมพ์ในหน้าต่างพิมพ์

## Windows / Mac (เคาน์เตอร์แคชเชียร์)

1. ติดตั้งไดรเวอร์เครื่องพิมพ์ (USB / LAN)
2. ตั้ง *Paper size* ของไดรเวอร์เป็น 80 × ยาวต่อเนื่อง (หรือ 58 มม.) และระยะขอบ 0
3. ใน Chrome: ครั้งแรกที่พิมพ์ เลือกเครื่องพิมพ์ → *More settings → Margins: None*, ปิด *Headers and footers*
4. (ไม่บังคับ) พิมพ์ทันทีไม่ต้องกดยืนยัน: เปิด Chrome ด้วย `--kiosk-printing`

## เคล็ดลับ

- แยกเครื่องพิมพ์ครัวกับแคชเชียร์: ใช้แท็บเล็ต/เครื่องคนละเครื่อง แต่ละเครื่องเลือกเครื่องพิมพ์ของตัวเอง
  และเปิด/ปิด “พิมพ์ใบสั่งครัวอัตโนมัติ” ได้ต่อเครื่อง (ตั้งค่าเก็บในเครื่องนั้น ๆ)
- QR โต๊ะ: พิมพ์บนกระดาษความร้อนแล้วใส่ป้ายอะคริลิก หรือกด *พิมพ์ QR ทุกโต๊ะ* แล้วเลือกเครื่องพิมพ์ A4
- QR โต๊ะหลุดออกไปนอกร้าน: *โต๊ะ & QR Code → แก้ไขโต๊ะ → QR ใหม่* (QR เก่าจะใช้ไม่ได้ทันที)
